# Customer Transaction Dashboard

A Power BI dashboard designed to analyze customer transactions, orders, products, locations, and transaction amounts.

## 📊 Project Overview

This project uses Power BI to transform customer transaction data into an interactive dashboard for analyzing:

* Customer activity
* Order volume
* Product count
* Transaction amount
* Average order value
* Location-level information

## 🛠️ Tools & Technologies

* **Power BI Desktop**
* **DAX**
* **Data Visualization**
* **Data Analysis**

## 📈 Key Measures

The dashboard includes the following DAX measures:

* **Total Customers**
* **Total Locations**
* **Total Orders**
* **Total Products**
* **Total Transaction Amount**
* **Average Order Value**
